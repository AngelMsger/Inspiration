# 代码问题：Coding Agent 读本仓库的克隆

八个设计或产品同学可能会问的、关于 Inspiration 自身行为和历史的问题。每个问题的正确答案都在任何运行之前写好，并附上 Coding Agent 从本仓库的干净克隆中给出的回答。它是[代码仓库作为知识来源](../../docs/zh/design/code-repositories.md)背后的第一次测量，也是一个基于真实代码和真实历史、而不是编造句子的评测集的起点。本文是 [README.md](README.md) 的中文副本，两者不一致时以英文版为准。

- [answers.md](answers.md)：实验设置、正确答案、Agent 的回答及其引用、评分，以及每次运行的 token、工具调用次数和耗时。

这些问题针对的是 4d5ea00 时的仓库。当问题涉及的代码或文档发生变化时，下次运行前要重新写正确答案，旧的运行结果保持原样。
