# Code questions: a coding agent over a clone of this repository

Eight questions a designer or product manager could ask about Inspiration's own behavior and history, each with its right answer written down before any run, and the answers a coding agent gave from a clean clone of this repository. It is the first measurement behind [Code repositories as a knowledge source](../../docs/design/code-repositories.md), and the start of an evaluation set on real code and real history, not invented sentences. A Chinese copy is in [README.zh.md](README.zh.md); if the two differ, this English version wins.

- [answers.md](answers.md): the setup, the right answers, the agent's answers with their citations, the scores and the tokens, tool calls and time of each run.

The questions are about the repository at 4d5ea00. When the code or the documents they ask about change, write the right answers again before the next run, and keep the old runs as they were.
